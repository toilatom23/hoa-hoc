# hoa-hoc

Trang web và công cụ hỗ trợ học Hóa học.

## Cấu trúc dự án

- `index.html`: Trang chủ giới thiệu hệ sinh thái học Hóa học với các mục giới thiệu, thống kê, chương trình học, thư viện, bộ công cụ, ứng dụng thực tiễn, tài nguyên tải về, cảm nhận học viên, tin tức, FAQ và biểu mẫu đăng ký.
- `styles.css`: Tệp định kiểu giao diện theo phong cách hiện đại, có hỗ trợ hiển thị trên thiết bị di động.

## Khởi chạy

Mở `index.html` bằng trình duyệt để xem trang web.
